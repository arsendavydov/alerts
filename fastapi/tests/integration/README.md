# Интеграционные тесты

Проверка API по HTTP. Нужен запущенный сервис и тестовая БД.

## Запуск (из папки fastapi/)

```bash
python3.10 -m pytest tests/integration/ -v
```

## Требования

- Сервис запущен (по умолчанию `http://localhost:8888/alerts`).
- Опционально: `TEST_API_URL` - базовый URL API.

Тесты создают и удаляют данные через API; очистка - в фикстурах.
