# E2E тесты

Сценарии полного цикла через API. Нужен запущенный сервис и тестовая БД.

## Запуск (из папки fastapi/)

```bash
python3.10 -m pytest tests/e2e/ -v -s
```

## Требования

- Сервис запущен.
- Опционально: `TEST_API_URL` (по умолчанию `http://localhost:8888/alerts`).

Сценарии в `e2e/scenarios/`. Флаг `-s` выводит логи в консоль.
